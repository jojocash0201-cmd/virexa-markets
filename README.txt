VIREXA MARKETS — V1 PROTOTYPE

Open index.html in a browser.

Included:
- Responsive public homepage
- Market quote cards (illustrative/demo data)
- Registration modal
- Login modal
- Client dashboard prototype
- Deposit/withdraw/trading buttons intentionally disabled

This is a UI prototype only. It does not process money, execute trades, perform KYC, authenticate users, or connect to a broker/liquidity provider.
